🔬 Finding: 15 Threads = Same ~2 docs/sec Ceiling

With 15 SO threads across 3 Entra apps, throughput was 1.99 docs/sec — virtually identical to the 5-thread baseline (2.05) and 10-thread test (2.02). Response times scaled proportionally (6,950ms avg vs 2,371ms at 5 threads), confirming the BC backend is serialising SO creation regardless of concurrency.

Model check: 15 threads / 6,950ms avg = 2.16 theoretical ≈ 1.99 observed — 92% efficiency. The throughput ceiling (~2 docs/sec) is set by BC's SO business logic, not API limits or number series.
