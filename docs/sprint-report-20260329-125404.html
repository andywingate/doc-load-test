✅ Baseline Confirmed: 2.05 docs/sec at 5 Threads

The 5-thread, single-app baseline is solid and consistent. This run (2.05/s, 2,371ms avg) closely matches the 11:51 endurance run (2.03/s over 5 full minutes) and the 11:47 sprint (2.08/s). The SO throughput ceiling of ~2 docs/sec is stable and repeatable.

This is the final run of the thread scaling study. Combined with the 10-thread (2.02/s) and 15-thread (1.99/s) tests, the conclusion is clear: adding SO threads does not increase throughput — only faster BC response times do.
