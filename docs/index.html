📖 About This Extension

doc-load-test v1.0.0.5 - Stress testing framework for Business Central Cloud APIs

Test Modes Available:

  • Validate: Quick smoke test (1 SO + 1 PO)
  • Full: Comprehensive load test with configurable document counts
  • Read: Read-only performance testing
  • Concurrent: Multi-threaded parallel creation
  • Race: Time-boxed maximum throughput test
  • Endurance: Long-running reliability test (hours)
  • DeepInsert: Single-call header + lines creation (NEW in v1.0.0.5)

API Endpoints: Custom v1.0 endpoints under /api/defaultpublisher/docloadtest/v1.0

Source: github.com/andywingate/doc-load-test
