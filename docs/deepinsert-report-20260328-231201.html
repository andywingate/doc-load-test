🔍 What is Deep Insert?

Deep Insert allows creating a complete document (header + all lines) in a single API call. Traditional approach requires 1 call for the header + N calls for lines = (N+1) total calls. Deep Insert requires just 1 call regardless of line count, dramatically reducing network overhead and improving performance.
