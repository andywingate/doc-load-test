🔬 Finding: 10 Threads = Same ~2 docs/sec Ceiling

With 10 SO threads across 2 Entra apps, throughput was 2.02 docs/sec — identical within noise to the 5-thread baseline (2.05) and 15-thread test (1.99). Response times doubled from the baseline as expected (4,694ms avg vs 2,371ms at 5 threads).

Model check: 10 threads / 4,694ms avg = 2.13 theoretical ≈ 2.02 observed — 95% efficiency. Adding threads simply makes each thread wait longer — the total work rate is unchanged.
